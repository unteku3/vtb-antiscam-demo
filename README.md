# ВТБ Антискам — UX-прототип

Учебный интерактивный прототип для кейса Changellenge Cup Moscow 2026. Это самостоятельная концепция, не официальный сервис и не приложение банка ВТБ.

## Что можно попробовать

Перевод → предупреждение → добавление переписки → объяснение риска → выбор действия или обращение в поддержку.

Три демонстрационных сценария:

- подозрительная просьба — платёж ради обещанной выплаты;
- оплата покупки — расчёт после осмотра товара;
- неполная переписка — требуется дополнительный контекст.

## Как работает демонстрация

Демонстрация начинается с объяснения продукта, затем проводит посетителя через пять шагов с контекстом и подсказками. Сайт состоит из статических HTML, CSS и JavaScript. Реальные переводы не выполняются, сообщения в банк не отправляются, AI-модель не подключена. Результаты примеров подготовлены заранее. Собственный текст или скриншот не анализируется: отображается подтверждение загрузки и предложение открыть подготовленный пример.

Выбранные файлы и введённые сообщения остаются в текущем состоянии браузера: приложение не отправляет их на сервер. Не загружайте настоящие пароли, коды или платёжные данные.

Для локального просмотра откройте `index.html` в браузере. Для публикации через GitHub Pages используйте корень ветки `main`; сборка и зависимости не требуются.

## Визуальные источники

Общая структура интерфейса основана на публичных экранах ВТБ Онлайн. Экраны Антискам созданы для этой концепции. Использован системный шрифт; фирменный Omega UI не включён.

- [Официальная карточка ВТБ Онлайн в RuStore](https://www.rustore.ru/catalog/app/ru.vtb24.mobilebanking.android)
- [Кейс редизайна ВТБ Онлайн, опубликованный ВТБ](https://workspace.ru/cases/redizayn-prilozheniya-vtb-onlayn-2/)

Наименование и визуальные элементы ВТБ используются для иллюстрации учебного кейса и не означают одобрение прототипа банком.
