# ВТБ Антискам: UX-прототип

Учебный интерактивный прототип для кейса Changellenge Cup Moscow 2026. Это самостоятельная концепция, не официальный сервис и не приложение банка ВТБ.

## Что можно попробовать

Если банковский ML-алгоритм замечает подозрительную операцию, перед переводом появляется плашка с предложением помощи и кнопкой «Пропустить и продолжить». Без сигнала ML перевод проходит без этой плашки. Помощник добровольный; пропуск не отменяет отдельные обязательные ограничения банка.

Клиент может рассказать о ситуации голосом, написать сообщение или добавить фото переписки. ИИ сопоставляет контекст с параметрами перевода. При признаках обмана или нехватке данных помощник сам подключает сотрудника ВТБ Онлайн и передаёт ему контекст. Сотрудник задаёт уточняющие вопросы, проверяет вывод ИИ и может его исправить.

Четыре демонстрационных сценария:

- Подозрительная просьба: платёж ради обещанной выплаты, разбор признаков обмана и проверка сотрудником.
- Оплата покупки: банк замечает нового получателя, но ИИ не находит явных признаков обмана в договорённости об оплате после осмотра. Это не гарантия безопасности сделки.
- Неполная переписка: данных недостаточно, сотрудник уточняет ситуацию.
- Обычный перевод: 2 500 ₽ знакомому получателю без сигнала ML и без плашки помощника.

## Как работает демонстрация

Демонстрация начинается с объяснения продукта, затем проводит посетителя по выбранному сценарию с контекстом и подсказками. Сайт состоит из статических HTML, CSS и JavaScript. ML-алгоритм и ИИ-модель не подключены: сигналы риска, разборы и ответы сотрудника подготовлены заранее. Реальных переводов и связи с сотрудниками банка нет.

Голосовой сценарий показан готовой расшифровкой рассказа клиента. Запись и распознавание голоса не выполняются, микрофон не включается. Собственный текст или скриншот можно добавить, но содержание не анализируется: демонстрация предлагает открыть подготовленный пример.

Выбранные файлы и введённые сообщения остаются в текущем состоянии браузера: приложение не отправляет их на сервер. Не загружайте настоящие пароли, коды или платёжные данные.

Для локального просмотра откройте `index.html` в браузере. Для публикации через GitHub Pages используйте корень ветки `main`; сборка и зависимости не требуются.
